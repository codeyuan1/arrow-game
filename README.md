# 一箭又一箭

一个用 Python + Pygame 开发的点击式箭头解谜小游戏。

## 游戏简介

棋盘上放着上、下、左、右四个方向的箭头。点击箭头后，程序沿箭头方向检查前进路径：

- **路径无阻** → 箭头飞出棋盘并消失
- **路径有挡** → 箭头原地晃动变红，消耗一次失误

清空全部箭头即可通关；失误次数耗尽则失败。

## 开发环境

- Python 3.12+
- Pygame 2.5.2

## 安装和运行

```bash
pip install pygame==2.5.2
python main.py
```

> Windows 下推荐使用微软雅黑字体显示中文，游戏会自动加载 `C:\Windows\Fonts\msyh.ttc`。

## 游戏操作

| 操作 | 说明 |
| --- | --- |
| 鼠标点击箭头 | 尝试消除该箭头 |
| 撤销 | 回退上一步（每关限 3 次） |
| 提示 | 高亮显示所有当前可飞出的箭头（每关限 3 次） |
| 重新开始 | 将关卡恢复到初始状态 |
| 返回选关 | 退出当前关卡 |

## 关卡设计

共 4 个关卡，由易到难：

| 关卡 | 棋盘 | 箭头数 | 失误上限 |
| --- | --- | --- | --- |
| 第 1 关 | 4×4 | 6 | 3 |
| 第 2 关 | 4×4 | 8 | 3 |
| 第 3 关 | 5×5 | 10 | 3 |
| 第 4 关 | 6×6 | 12 | 4 |

所有关卡均经过自动求解器验证，保证存在合理的通关顺序。

## 核心实现

### 方向与路径检测

```python
DIRS = {
    'UP':    (-1, 0),
    'DOWN':  (1, 0),
    'LEFT':  (0, -1),
    'RIGHT': (0, 1),
}

def get_blocker(board, r, c, direction):
    dr, dc = DIRS[direction]
    nr, nc = r + dr, c + dc
    rows, cols = len(board), len(board[0])
    while 0 <= nr < rows and 0 <= nc < cols:
        if board[nr][nc] != 0:
            return (nr, nc)   # 返回阻挡者坐标
        nr += dr
        nc += dc
    return None              # 畅通
```

从点击位置出发，沿方向逐格扫描：遇到非空格子 = 被阻挡（返回阻挡坐标），走出边界 = 畅通（返回 None）。

### 飞出与碰撞动画

- **飞出**：箭头沿方向渐隐移动（alpha 从 255 减到 0，位置沿 dirs 偏移增长）
- **碰撞**：箭头通过 `sin(t * 0.8) * 6` 产生左右晃动 + 颜色变红，持续 20 帧

## 音效说明

所有音效均使用 Python `math.sin` + `struct.pack` **程序化合成**（sine 波 PCM），不加载任何外部 wav/ogg 文件，因此：

- ✅ **零版权风险**：代码自己算出来的波形，不是外部素材
- ✅ **GitHub 仓库干净**：不需要 `assets/` 目录
- ✅ **四种音效**：飞出（高音短音）、碰撞（柔和低频）、通关（上行旋律 C→E→G→C）、失败（下行旋律 G→E→D）
